## Findings

**F1. `yangMills_haagKastler` has no Yang–Mills content beyond its hypothesis.** `Main.lean:316`, severity: note.
The proof takes `JointExistence` (`ChallengeSpec.lean:186`), destructures it, and applies `wightman_to_haagKastler` to `hT.reconstruction.axioms`. The conclusion is `JointExistence` with "this Wightman theory has a polynomial HK net" appended, and that holds for every W0–W3 theory. The repo neither imports nor checks `YangMills.jointExistence`. `REPORT.md:3` opens with "Lean 4 (v4.32.0) proof that the Wightman theory of the Yang–Mills construction ... yields a net". That sentence holds only conditionally on `JointExistence`, which the report states further down but not in the opening sentence. The D3 fix is real: the net is now the hierarchy's own net, not an unrelated witness.

**F2. `bounded_haagKastler` restates its hypotheses, and the one field tying it to the Wightman fields is unused.** `BoundedNet.lean:31-44, 171-203`, severity: minor.
Einstein causality follows directly from the `commute` field, covariance from `covariant`, and isotony from `mono`. The `affiliated` field, which D5/D6 added to tie `S(O)` to the fields, appears in no proof. `hT` is unused as well (see the lint warning above). So the theorem is the generic fact that double commutants of an isotonous, local, `Ad U`-covariant self-adjoint family form an HK net. That fact holds for any such family, whether or not it has anything to do with the theory. No instance of `BoundedLocalData` is constructed for any theory, including the free field, so the repo never shows the hypotheses can be met in a nontrivial case. I checked non-vacuity: D6's rank-one argument is correct, since with `S(O)` scalar, `affiliated` forces the fields localised in `O` to be scalar. The hypotheses are consistent in the trivial one-dimensional theory (`S = B(H)`). Also, `affiliated` is the weak form `B φ ⊆ (φ†)* B`. That is weaker than affiliation (`B φ̄ ⊆ φ̄ B`) when `φ` is not essentially self-adjoint, yet `README.md:58` says "with the fields affiliated" without qualification.

**F3. GNS naming and README overstate what B2 leaves open.** `WightmanVacuum.lean:121` (`gns_recovers_wightman`), `README.md:24` ("GNS recovers the fields"), severity: minor.
`wightmanGNS` lives on `K = closure(A(M)Ω)`, where `A(M)` uses only compactly supported tests. `K = H` is not proved. `REPORT.md` and `BLOCKERS.md` B2 state this correctly. The theorem name and the README file table do not. Vacuum uniqueness and the spectrum condition are proved on `K` by inheritance from W0 on `H`, which is correct. What is not established is that the Wightman theory on `H` is the vacuum representation in FR's Def. 25 sense.

**F4. The `Timeslice` definition differs from FR A5.** `HaagKastler.lean:57`, severity: note (unclaimed).
FR A5 (p. 14) says: "If O₁ ⊂ O₂ and O₁ contains a Cauchy surface of O₂ then A(O₂) = A(O₁)", with Cauchy surfaces defined by timelike curves. The Lean version uses `O₂ ⊆ dependenceDomain O₁` with inextendible causal curves. These are different hypotheses. Since timeslice is not claimed, this changes no theorem. `AUDIT.md` lists it as harmless without proving the two forms equivalent.

## Fidelity checks that passed

- **Regions.** FR A1 indexes by "open causally convex bounded" regions. Lean adds `nonempty` (harmless), and `CausallyConvex` is order-convexity for the closed causal order, which is equivalent in Minkowski space. `forwardCone` is the closed cone and `spacelike` is strict, so `CausallyDisjoint` matches FR.
- **Net, isotony, causality.** FR asks for subalgebras of `A(M)`. Lean uses injective, functorial unital *-homs; with a directed index set (proved, `Region.exists_common`) the colimit recovers `A(M)`. Einstein causality matches FR A3.
- **Covariance.** Per-region *-isos with naturality, `one` and `mul` through `incl` are equivalent to FR A4. `poincareMul` matches upstream `productCoordinates`. `ProperLorentz` (det 1, preserves the Minkowski form and `V₊`) is FR's `P₀`.
- **`PolynomialNet.lean`.** `P(O) = Algebra.adjoin ℂ {φ(l,f) : tsupport f ⊆ O}`. Since `O` is bounded and open, `f` has compact support in `O`. The star is the unique formal adjoint on `D` (uniqueness from density, existence in `P(O)` from W1 `AdjointAxiom` and `tsupport_conjugateTest`). `polynomialAct` is `X ↦ V X V⁻¹` with `V = onStates (coordinates.symm g)` restricted to `D`, and `tsupport_onTests` is derived from upstream `pullback`, so it carries no extra assumption. The net is concrete, so its conclusions cannot be met by an unrelated witness. If all fields are zero the net is scalar, which is correct, and upstream `Reconstructed.acts` excludes that for Yang–Mills.
- **`Vacuum.lean`.** The GNS structure matches FR Thm 10: dense domain `= π(A)Ω`, expectation, and formal-adjoint star. The spectrum condition through vector-state measures is equivalent to `supp E ⊆ V̄₊` by uniqueness of the measure behind `charFun`. FR Def. 24 uses `U(x)=e^{iP_μx^μ}`, and upstream uses the Euclidean pairing, so the two differ by `p⃗ ↦ −p⃗`, which preserves `V̄₊`, as D4 says. `IsVacuum` requires Poincaré invariance, which is stronger than FR Def. 25. The existentials over `R` and `U` cannot be exploited: GNS representations are unique up to equivalence, and `implements` fixes `U` on a dense set.
- **GFF counterexample (`TIMESLICE.md` §2).** The argument is correct. The one-particle projection of any `X ∈ P(O₁)` applied to `Ω` is `[h]` with `supp h ⊆ O₁`. `ρ` = Lebesgue measure on `[1,2]` forces `(f−h)^ = 0` on an open set of momentum space. Paley–Wiener then gives `f = h`, a contradiction. The region choice (double cone `D(B)` and slab `D(B) ∩ {|t|<ε}`) meets the Lean timeslice hypothesis.

## What this establishes, for a mathematical physicist

For any Wightman theory satisfying the upstream W0–W3 (fields on a common dense invariant domain `D`, adjoint relation, covariance under a unitary `P₀` representation, locality), the Lean code checks this: the algebras `P(O)` of polynomials in smeared fields with test functions compactly supported in bounded, open, causally convex `O`, with the formal adjoint on `D` as involution, form a net of unital *-algebras satisfying FR A1–A4. Covariance is implemented by `X ↦ U(g)XU(g)⁻¹`. Mathematically this is elementary, since isotony is inclusion of generating sets, causality is W3 and covariance is W2. The value of the code is in getting the definitions right, and they are right. Timeslice (A5) is not proved, and for this kind of net it is false in general, as the generalized free field shows. The vacuum expectation value is a Poincaré-invariant state satisfying the spectrum condition, unique as a vacuum on the GNS space `closure(P(M)Ω)`. Whether that space is all of `H` is open. The Yang–Mills statement says nothing beyond this general result: if the upstream `JointExistence` holds, the resulting theories carry such nets. This repo does not check `JointExistence`. The von Neumann net result is a conditional, generic statement whose link to the fields is never used, and its hypotheses are not shown to hold for any interacting theory. Nothing here bears on dynamics, a mass gap, or any property that distinguishes Yang–Mills from a free or generalized free field.
