## Summary

Statements and definitions in `Regions.lean`, `HaagKastler.lean`, `PolynomialNet.lean`
(with `Conjugation.lean`, `Locality.lean`) and `Main.lean` were compared against
Fewster-Rejzner (arXiv:1904.04051, Sec. 4.1, axioms A1-A5) and the upstream Wightman spec
(`ym_core/PublicTheory.lean`, `ym_core/ChallengeSpec.lean`, pinned rev `3456e5e`).

No deviation makes a statement unfaithful, false in spirit, or trivial. All deviations are
standard reformulations (abstract injective-inclusion net instead of subalgebras of A(M);
per-region isomorphisms with naturality instead of automorphisms of A(M); order convexity
instead of curve convexity; dependence-domain timeslice instead of Cauchy-surface timeslice)
and are equivalent or harmless in Minkowski space. No `sorry`, `axiom`, `admit`, `opaque` or
`implemented_by` occurs in the project sources. `yangMills_haagKastler` (post-D3) cannot be
discharged by a cheap witness: its conclusion contains `T.Properties (p ∘ q)` and so implies
`JointExistence` itself.

Numbering note: FR numbers the axioms A1 local algebras, A2 isotony, A3 Einstein causality,
A4 Poincare covariance, A5 existence of dynamics (timeslice). This audit uses FR's numbering.

## Regions

- Geometry is imported from upstream: `Spacetime = EuclideanSpace ℝ (Fin 4)`, time is
  `Fin.last 3` (last coordinate), `forwardCone = {‖spatial x‖ ≤ time x}` (closed),
  `spacelike = {minkowskiSquare x < 0}` (strict). Same objects W3 uses, so the AQFT and
  Wightman statements share one geometry.
- `CausalLE x y := y - x ∈ forwardCone`: closed causal future (J+), reflexive. Correct.
- `CausallyDisjoint A B := ∀ x ∈ A, ∀ y ∈ B, x - y ∈ spacelike`. FR: no causal curve joins
  O1 and O2. `x - y ∉ J+ ∪ J-` iff `‖s‖ > |t|` iff `t² - ‖s‖² < 0`, so this is exactly
  strict spacelike separation. Matches FR and upstream `SpacelikeSeparated`.
- `CausallyConvex A`: order convexity for `CausalLE`. FR (footnote 5): contains every causal
  curve with endpoints in it. In Minkowski space these agree: a causal curve from x to z lies
  in J+(x) ∩ J-(z); conversely x ≤ y ≤ z gives the broken straight causal curve x→y→z.
  Quantifying over all x, z ∈ A covers past-directed curves too.
- `InextendibleCausalCurve`: continuous, monotone for the closed causal order, time → ±∞ at
  ±∞. In Minkowski space a future-directed causal curve is inextendible iff its time is
  unbounded in both directions, so this is the right class.
- `dependenceDomain A`: points x such that every inextendible causal curve through x meets A.
  Standard D(A).
- `Region`: open, bounded, causally convex, plus `nonempty`. FR A1 indexes by open causally
  convex bounded regions. Adding nonemptiness drops only ∅; harmless. The type is inhabited
  (double cones) and directed (any two bounded regions lie in a large double cone), which is
  what makes the abstract formulation below equivalent to FR's.
- `poincareAct (Λ, a) x = Λ x + a`. Matches upstream `pullback`
  (`onTests g f x = f (Λ⁻¹ (x - a))`), whose support is `poincareAct g '' supp f`
  (proved as `tsupport_onTests`).
- `poincareOne = (1, 0)` matches `identityCoordinates`.
- `poincareMul g h = (Λ_g Λ_h, Λ_g a_h + a_g)` matches `productCoordinates` exactly, and
  `poincareAct (poincareMul g h) = poincareAct g ∘ poincareAct h` (`Region.map_mul`).
- `ProperLorentz` (upstream): det 1, preserves `minkowskiSquare`, preserves the forward cone,
  i.e. the proper orthochronous group, the identity component P0 used in FR A4.
- `Region.map g O`: image under `poincareAct g`, with openness, boundedness, nonemptiness and
  causal convexity proved, so the action really lands in `Region`.

## Haag-Kastler axioms

- `Net`: for each region a ℂ-algebra with star ring and star module structure (unital
  *-algebra), and `incl : O₁ ⊆ O₂ → Alg O₁ →⋆ₐ[ℂ] Alg O₂`. `StarAlgHom` over ℂ is unital
  (`AlgHom` preserves 1), matching FR's "subalgebra containing the unit".
- `Isotony`: inclusions injective, `incl refl = id`, `incl` composes. FR A1/A2 state
  A(O) ⊆ A(M) with A(O1) ⊆ A(O2). Given directedness, an injective functorial system is
  equivalent to FR's: take A(M) as the directed colimit (union) of the A(O); the maps into it
  are injective, A(M) is generated by the A(O) automatically, and nestedness is `incl`.
- `EinsteinCausality`: for causally disjoint O1, O2 inside any common O, the images in A(O)
  commute. FR A3 asks commutation in A(M). Since a common O always exists and `incl` are
  injective homomorphisms, commuting in one common O, in every common O, and in the colimit
  are equivalent.
- `Timeslice`: `O₂ ⊆ D(O₁)` makes `incl` surjective. FR A5: O1 contains a Cauchy surface of
  O2, then A(O2) = A(O1). These hypotheses are close but not literally identical. Timeslice is
  not claimed by any main theorem, so this has no effect on the results.
- `Covariance`: per-region *-isomorphisms `A(O) ≃ A(gO)` for g in P0 coordinates.
  `Covariant`: naturality with `incl`, `α(1)` = inclusion between equal-carrier regions,
  `α(g) ∘ α(h)` = inclusion ∘ `α(gh)`. FR A4: automorphisms α(Λ) of A(M) with
  α(Λ)A(O) = A(ΛO), α(id) = id, α(Λ)α(Λ') = α(ΛΛ'). Naturality is exactly the condition for
  the per-region isomorphisms to glue to an automorphism of the colimit mapping A(O) onto
  A(gO); the identity and composition laws then give FR's group law. Equivalent.
- `Axioms` bundles all four. FR has no continuity requirement on α at the *-algebra level;
  none is imposed here either.

## Polynomial net

- `localGenerators F A = {φ(l, f) | tsupport f ⊆ A}` over all labels and all Schwartz f;
  `polynomialAlgebra F A = Algebra.adjoin ℂ (localGenerators F A)` in `End(D)`. This is the
  unital algebra generated by fields smeared with test functions supported in A. For bounded
  open O, `tsupport f ⊆ O` forces compact support in O, so these are the usual D(O)-smeared
  fields.
- Star: `IsFormalAdjoint X Y := ∀ u v ∈ D, ⟨X u, v⟩ = ⟨u, Y v⟩`. Uniqueness uses W1
  `denseDomain`; existence inside P(O) uses W1 `AdjointAxiom` and
  `tsupport (conj f) = tsupport f`, then induction over the adjoin. The `choose` in `polyStar`
  is canonical because of uniqueness. So star is the formal adjoint on D, and the star ring and
  star module laws follow from the uniqueness of formal adjoints.
- `incl` is `Subalgebra.inclusion`, so injectivity is genuine and not built into the structure.
- Covariance: `domainEquiv g u = onStates (coordinates.symm g) u` restricted to D (W2
  `domainInvariant`), inverse `onStates (coordinates.symm (poincareInv g))`, two-sided by
  `productCoordinates`/`identityCoordinates`. `domainConj g = (domainEquiv g).conjAlgEquiv`,
  i.e. `X ↦ U(g) X U(g)⁻¹` on D. `polynomialAct g O` is this map restricted to P(O), landing
  in P(gO) via W2 `fieldCovariance` and `tsupport_onTests`, and it is onto P(gO)
  (`polynomialAlgebra_map_domainConj`). `polynomialCovariance := ⟨polynomialAct T hT⟩`.
  This is exactly the D3 caveat's required implementation.
- Degeneracy check:
  - No structure field is trivially satisfiable: `Covariance` is data, and the laws in
    `Covariant` are about this specific conjugation.
  - `Region` is inhabited, so the net is not indexed by an empty type.
  - Hypotheses `T.Axioms` are upstream W0-W3. In the Yang-Mills case they are supplied by
    `Reconstructed.axioms`, and `Reconstructed.acts` guarantees some nonzero smeared field, so
    the net there is not the scalar net. For a theory with all fields zero P(O) = ℂ for every O;
    that is the correct net of that theory, not a vacuity in the statement.
  - W0 is assumed but not used by the proofs; this only makes the hypothesis stronger than
    needed and matches "W0-W3".

## Main statements

- `wightman_to_haagKastler (T) (hT : T.Axioms)`: the polynomial net of T satisfies `Isotony`,
  `EinsteinCausality`, and `Covariant (polynomialCovariance T hT)`. This states "W0-W3 give a
  Haag-Kastler net with isotony, causality and covariance" with the net and the covariance
  pinned to the canonical constructions, so it cannot be met by an unrelated net. Timeslice is
  excluded and the docstring says so.
- `yangMills_haagKastler (hYM : JointExistence)`: same Wilson family, regularity, refinement and
  hierarchy shape as `JointExistence`, keeps `T.Properties (p ∘ q)`, and asserts the
  three axioms for `polynomialNet T.theory hax`. The conclusion implies `JointExistence`, so
  it is exactly as hard as the upstream result plus the Wightman-to-AQFT step and is not
  satisfiable without the hypothesis (or an independent proof of `JointExistence`). The
  pre-D3 constant-net loophole is closed because the net is now tied to `T.theory`.
- `hax : T.theory.Axioms` is existentially quantified; it is a `Prop` so the net does not
  depend on which proof is chosen.
